# PETS–AEGIS Historical Device Registry

Read-only demonstration of the historical device inventory. This Space template contains only device model names and their historical/unverified classification.

No device telemetry, government identification, account credentials, unique hardware identifiers, or biometric data are collected. Do not upload sensitive evidence to a public Space.
